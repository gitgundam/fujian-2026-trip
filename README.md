# 福建，沿海慢行

手机优先的静态旅行指南。布局、样式、交互均从零重构。

## 本地打开

在项目根目录运行：

```sh
python3 scripts/serve.py
```

打开 http://127.0.0.1:8773 。使用 HTTP 服务器打开，不要双击 HTML：浏览器的本地文件安全策略会限制 ES modules。

这是预览服务器，不是网站后端。部署时直接托管仓库根目录即可，不需要构建或服务端改写规则。

## 页面与数据

- `index.html`：全程地图、播放与暂停、选站与预览。
- `cities/*.html`：六个独立站点页面。`?day=10-03` 可分享指定日期，`#spot=beigang` 可直接打开景点。
- `stays.html`、`essentials.html`、`credits.html`：全程住宿、随行提醒、图片与资料来源。
- `assets/data.js`：八天行程、城市、景点、酒店与提醒的单一内容来源。
- `assets/photos.json` / `assets/photos.js`：图片文件、来源页、作者、许可和状态。JSON 是资料清单；修改后保持 JS 导出一致。
- `assets/coast.js`：由 Natural Earth 1:50m 陆地数据裁取的海岸 SVG 几何；城市坐标与路线在 `map.js` 中。线条是城市间示意，不是驾车导航。
- `assets/style.css`：响应式布局、图文排版与动画。字体为本地 Noto Serif SC 子集，许可见 `assets/FONT-LICENSE.txt`。

不使用地图 API Key、账户或后端。图片和字体均在本地，不依赖外部 CDN 才能阅读。点击导航、酒店平台和来源链接时才访问外部站点。

## 交互约定

初次打开默认选中平潭；之后使用 sessionStorage 记住当前标签页内选中的城市、日期和阅读位置。不会推测当天实际到达的城市，也不会把行程完成作为既定事实。

手动选站会停止并重置全程播放。隐藏标签页时暂停；完成后回到桐乡，可重播。减少动态效果开启时，取消移动光点及平滑转场，保留逐站内容切换。

景点面板使用原生 dialog：支持拖动顶部把手、展开/收起按钮、Escape、焦点限制和浏览器返回。照片大图是独立的一层历史记录。已订与候选明确分开，只有艾思顿在既有资料中已订。

## 内容边界

行程事实来自本地《福建国庆自驾攻略.md》，资料日期 2026-09-23。只补充照片，没有新增餐馆、重新核价或更改整体行程。平潭酒店、东渡取消规则、赶船时刻等资料差异已在相关位置标明。

32 个景点均有对应实景，合计 37 张；图片拍摄时间不同，来源页和许可逐项保留。桐乡、涵江、晋江中转封面使用文字插画，没有用其他地方的照片冒充。
